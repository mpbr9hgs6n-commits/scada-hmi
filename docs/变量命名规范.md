# 变量命名规范（组态表达式）

> 品牌：陆祺智控（LUQI SMART CONTROL） · 2026-11-08
> 适用范围：组态动态化、事件动作、报警点位、趋势曲线、文本/图形列表。
> 一句话：**站点用 `S` + 三位数字，点位用大写英文缩写，中文只出现在标题里，绝不转拼音。**

---

## 一、三段式全名

```
<站点ID>.<点位代号>
   S001   .  LEVEL
```

| 段 | 规则 | 例 |
|---|---|---|
| 站点 ID | `S` + 三位数字，从 S001 起，**与设备台账编号一致**，不重用已废弃号 | `S001` `S137` `S200` |
| 点位代号 | 大写字母开头；只用 `A-Z` `0-9` `_`；≤ 32 字符；同一站点内唯一 | `LEVEL` `PH` `FLOW` `PUMP1_RUN` `VALVE1` |
| 分隔 | 中间一个英文句点 `.`，两边不要空格 | `S001.PUMP1_RUN` |

**禁止**：

- 拼音（`ye_wei`）、中文（`液位`）、日文假名、空格、`-`（解析器把 `-` 当减号）。
- 用序号占位（`P1` `P2`）而不带含义——半年后没人知道 `P3` 是什么泵。
- 站点号与点位号写反（`LEVEL.S001`）。

## 二、推荐的点位代号词表（按工艺段）

| 类别 | 词根 | 例 |
|---|---|---|
| 模拟量 | 工艺量英文缩写 | `LEVEL`（液位 m）`PH` `FLOW`（流量 m³/h）`PRESS` `TEMP` `DO`（溶解氧）`TURB`（浊度） |
| 设备状态 | `设备号_RUN` / `_FAULT` / `_REMOTE` | `PUMP1_RUN` `PUMP1_FAULT` `BLOWER2_REMOTE` |
| 设备命令 | `设备号_CMD` | `PUMP1_CMD` `VALVE3_CMD` |
| 阀门位 | `VALVE<n>_OPEN` / `_CLOSE` | `VALVE1_OPEN` `VALVE1_CLOSE` |
| 累计量 | 后缀 `_TOTAL` | `FLOW1_TOTAL` |
| 设定值 | 后缀 `_SP` | `LEVEL_SP` `PH_SP` |
| 报警位 | 后缀 `_ALM` | `LEVEL_HH_ALM` |

设备号规则：**同类型设备从 1 连续编号**（`PUMP1` `PUMP2`…），不要 `PUMP01` 与 `PUMP1` 混用。

## 三、表达式怎么写

当前站点可省略站点号（裸名 = `@CurrentSite + '.' + 代号`）：

| 写法 | 含义 | 什么时候用 |
|---|---|---|
| `S001.LEVEL` | 指定站点，绝对引用 | 单站画面、跨站对比 |
| `LEVEL` | 当前站点（`?site=` 决定） | 通用画面 |
| `@CurrentSite` | 当前站点 id（字符串） | 拼名字、显示标题 |
| `@CurrentSite + '.LEVEL'` | 间接变量连接 | **一张画面铺 200 个站**，首选 |
| `@Tag("S001." + "LEVEL")` | 拼出来的变量名 | 站号来自别处（如文本对象） |
| `@Quality("S001.LEVEL")` | 质量码：`0` 正常 / `1` 坏值 / `-1` 不存在 | 做「通信中断」提示 |

运算与判断（白名单，不是 `eval`）：

```
LEVEL * 100              算术 + - * / %
LEVEL > 3.5 ? 1 : 0      比较 + 三元
"站点 " + @CurrentSite   字符串拼接
```

**不支持**：函数定义、循环、赋值、对象字面量、`Math.*`。需要复杂逻辑就在网关侧算好，组态只读结果。

## 四、四类数据类型怎么影响写法

| 数据类型 | 值怎么来 | 写表达式的注意点 |
|---|---|---|
| `Analog` | 数值原样，按「值域」映射 | 最常见的液位/流量都用它；值域要覆盖**现场实际量程**，别用 0~100 |
| `Bool` | 非 0 视为 1 | 只配两档（0 档 / 1 档） |
| `Bit` | 取第 N 位（0 位最低位） | 一个 WORD 拆多路状态时用；`bit` 从 0 数 |
| `Direct` | 不映射，值直接赋给属性 | 只用于数值/可见性，**别拿来改颜色**（颜色要写 `#rrggbb`） |

## 五、命名与量程一起定（不然曲线和报警全是废的）

每个模拟量点位必须同时给：`单位`、`量程下限`、`量程上限`、`死区(deadband)`。

- 死区 = 量程的 0.5%~2%（例：0~3.5 m 的液位取 0.02~0.07）；**开关量死区必须为 0**，否则状态变化会被抹掉。
- 量程填错的表现：液位罐永远满格（值长期 >上限 → 高度恒 100%）、报警永不触发。

## 六、200 个站点怎么保证不撞名

1. 站点号由台账分配，**一人登记**，新建站点前先查 `/api/site`。
2. 点位代号只在本站内唯一，跨站靠站点前缀区分；不建议为了全局唯一去加站号（会破坏 `@CurrentSite` 复用）。
3. 铺站前先跑预览表：它会逐站列出「替换几处 / **无效点位几个**」，无效点位不为 0 就别执行。
4. 改点位代号前先搜引用：`grep -o '"[^"]*\.代号"' ` 于画面 json（或列表页搜索），改完必须重跑 `python check_scada.py`。

## 七、反面例子（现场真实踩过的）

| 写法 | 问题 | 改成 |
|---|---|---|
| `液位` | 中文标识符，表达式解析不到 | `LEVEL` |
| `ye_wei` | 拼音，交接没人认 | `LEVEL` |
| `S1.LEVEL` | 站点号位数不统一，铺站替换会错位 | `S001.LEVEL` |
| `S001.LEVEL_1` / `S001.LEVEL1` | 同义不同名，趋势拉不到一起 | 统一 `LEVEL`，多台设备用 `LEVEL1/LEVEL2` |
| `LEVEL > 3.5`（直接写在「值域」框里） | 值域框只吃数字，不吃条件 | 用「动态对话框」配 3.5 这一档，或用三元表达式 `LEVEL>3.5?1:0` |
