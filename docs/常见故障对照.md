# 常见故障对照（组态 / 画面 / 控件）

> 品牌：陆祺智控（LUQI SMART CONTROL） · 2026-11-08
> 只收**组态侧**的故障。平台级（数据库、采集、视频服务）看《部署手册》第九节。
> 每一行都标了「怎么确认不复发」——对应 `verify.sh` 的检查项或 `check_scada.py` 的条号，改完必须能过。

## 一、画不出来 / 画了没反应

| 现象 | 根因 | 处置 | 确认不复发 |
|---|---|---|---|
| 新建的画面在左侧树里找不到 | `POST /api/page` 没带 `site_id`：树按「公共模板 / 站点分组」两棵树展示，没有站点的 scada 画面只能靠 URL 直接开 | 新建时就选站点；已建错的用「重命名」旁的编辑补站点 | `check_scada` 03 项 |
| 树里明明有站点，行却不显示 | 「站点画面」组和具体站点默认**折叠** | 点组名前的三角展开两层 | 同上 |
| 拖完对象坐标不是 20 的倍数 | 用了 `offsetLeft` / 截图量位置，被 `transform:scale()` 缩放吃掉小数点 | 看拖动时的 `x / y` 读数，或 `Ctrl+S` 后读 `/api/page/<id>` 的 `json.items[].x/y` | `check_scada` 04 项 |
| 想微调却一直吸附 | 20px 网格是默认行为 | **按住 Alt 拖动**（要在按下鼠标之后再按，先按住 Alt 再按下会丢） | `check_scada` 04 项（Alt 分支） |
| 撤销按了没反应 | `Ctrl+Z` 只在画布聚焦时生效；焦点在输入框里会被让开 | 先点一下画布空白再按 | `check_scada` 06 项（60 步连续撤销） |
| 多选拖不动 | 普通点击会**清掉前一个选择** | 第一个普通点，后面的用 `Shift` 加选 | `check_scada` 05 项 |

## 二、值不对 / 不动

| 现象 | 根因 | 处置 | 确认不复发 |
|---|---|---|---|
| 画面数值全是 `--`、对象标黄 | 绑的点位不存在 / 表达式写错 / 该站点没连上 | 看属性面板「动态化」的表达式；裸名要保证 `?site=` 指向的站点有点位 | `check_scada` 08/11 项 |
| 切了站点数字不变 | 只改了下拉框，没调 `rt.setSite()` | 用页面右上角站点选择器（内部会重连 + 立即重算 + 改 `?site=`） | `check_scada` 09 项 |
| 一张画面复用到 200 个站，值全一样 | 写的是 `S001.LEVEL` 绝对引用 | 改成 `@CurrentSite + '.LEVEL'` 间接连接；铺站预览确认「替换处数」不是 0 | `check_scada` 09 项、`verify.sh` 71 |
| 液位罐永远满格 | 值长期高于量程上限（如量程填 0~1，实际 3.x） | 按现场实际量程改点位量程；判据是 `高度 ≈ min(100, v/上限*100)` | `check_scada` 08 项 |
| 液位罐卡在满格「不动」但数值在跳 | 模拟器曲线摆幅超出量程（例：曲线 3.0±0.8 上限 3.8 > 量程 3.5），约 1/3 时间超程，两次采样都被夹到端点 100% | 曲线要**大部分时间落在量程内**（现为 2.0±1.7 → 0.3~3.7），`docker compose up -d --build gateway` | `check_p4` 第 1 项 |
| 动态对话框永远只走绿/黄，橙/红档采不到 | 曲线上限低于最高档边界（例：1.7±1.5 最高 3.2，永远到不了 3.5），红档+闪烁无从验证 | 曲线要周期性越过最高档边界（现约 15% 时间 >3.5，周期约 63 秒）；超程时高度按规则封顶 100% 属正常 | `check_scada` 第 10/12 条 |
| 高度与数值对不上（h=100 但值 3.2） | 验收脚本先读 DOM 再调 `snapshot` 接口，两次读数有 ~1 秒时差 | 用对象**自身文本**里的值当期望（与高度同一渲染帧）；曲线越快，时差偏差越大 | `check_scada` 第 08 条 |
| **液位一超量程就变空罐** | **动画的高度轨道在最后一档之外拿到的是「其他」颜色串 → `pctFromValue` 算回 0%** | 已修：数值类属性（高度/不透明度/数值/闪烁/角度）未命中区间时**夹到端点档位值**，不吃颜色 | `verify.sh` 77、`check_scada` 12 项 |
| 动态对话框四档只走到一档 | 档位边界定在现场实际值域之外（例：边界 3.5，实际只在 2.2~2.8 之间走） | 边界要覆盖现场实际波动范围；采样时剔除 ±0.12 的边界样本 | `check_scada` 10 项 |
| 一个变量想同时改颜色和高度，只能生效一个 | 「动态对话框」一个对象只认一条主绑定 | 用「动画」模式：一个触发变量 + 多条轨道（高度/颜色/闪烁各一条） | `check_scada` 12 项 |
| 文本列表/图形列表不生效 | 值列表没建，或列表项的值与点位类型不匹配（文本表拿数值去比字符串） | 先在 `/scada` 建值列表，列表项的「值」按点位实际类型填 | `verify.sh` 69 |
| **I/O 域输入框里的数字自己变回过程值** | `mode=input`（仅输入）本该只显示默认值/用户键入，但实时刷新把过程值推进去了（等于退化成输入输出） | 已修：`patch` 跳过 `mode=input`；想边看当前值边改就选「输入输出」 | `verify.sh` 107、`check_fix2` 第 3b 条 |
| 键入后回车，红框提示「没有可写回的点位」 | 动态化表达式不是单个变量（如 `@CurrentSite + '.LEVEL' * 2`），反解不出写回目标 | 写回只支持 `S001.LEVEL` / `LEVEL` / `@CurrentSite + '.X'`；算出来的值在网关侧算 | `已知限制` 第 24 条 |

| 测试地址填 vd1000 / x10 被判红 | 校验区分大小写 | 已修：前后端校验前统一 upper；S7 提示补 VD1000 | `verify.sh` 112 |

## 三、按钮与写值

| 现象 | 根因 | 处置 | 确认不复发 |
|---|---|---|---|
| **泵停不下来（线圈停在 1）** | **瞬时动作漏了 `mouse.leave`；按住拖出按钮再松手，`mouseup` 落在页面上，对象收不到 release** | 用「瞬时」预设（自动三条且 `mouse.leave` 锁定不可删） | `check_scada` 15、`verify.sh` 75 |
| 瞬时按钮偶发停在 1（三条都配了） | 松开那一下撞上「上一条写还没回来」，被防连点直接丢掉 | 已修：被挡时**记下终值，等回来立刻补发**；且 document 级兜底保证松手一定执行一次 release | `verify.sh` 75/76 |
| 点击按钮没反应 | 动作绑在 `mouseup` 但对象被别的图元盖住；或改了事件没重新绑定 | 事件面板提交后自动 rebind；检查图层顺序（被盖住的对象点不到） | `check_scada` 14 项 |
| 点一下写两次 | 同值连点；或同时配了 `mouse.click` 与 `mouse.release` | 300ms 内同值只发一次；一个动作只绑一条事件 | `verify.sh`（连点审计计数） |
| 写成功但设备没动 | 网关没真写进去（历史版本不回读） | 写回链路强制 200ms 回读比对，不一致报「写入失败：回读为 X」 | `check_scada` 16、`verify.sh` 52/53 |
| 只读点位也能点 | 只在前端禁用 | 后端 `/api/write` 校验 `rw=0 → 400「该点位只读，禁止写入」`；不存在的点位 `404` | `check_scada` 16 项 |
| 拖出一个按钮松手，别处的按钮跟着变 | 多个按钮共用同一个点位且都绑了瞬时 | 一个点位只给一个瞬时按钮用；要一对多改用「取反」或中间点位 | — |

> 回读不一致那条分支**造不出来**是正常的：演示用的 Modbus 模拟器会忠实回写（写 12345 读回 12345）。所以验收只验「正常写 + 只读 400 + 不存在 404」，不一致分支靠代码审查（`gateway/collector.py` 写后回读比对 → 400；`backend/app/api/health.py` → 409）。**不造假样本。**

## 六、改了代码不生效（最常见，先查这条）

| 现象 | 根因 | 处置 |
|---|---|---|
| 改了 `src/*.js` 但页面没变化 | nginx 挂的是 `/opt/plant/frontend/dist`，只传源码不重建 | `docker run --rm -v /opt/plant/frontend:/app -w /app node:20-alpine sh -c 'npm run build'`；传完先 `md5sum` 比对两边 |
| 改了 `gateway/*.py` 但采集逻辑没变 | 只 `restart` 没 `--build`，容器里还是旧镜像 | `docker compose up -d --build gateway` |
| 改了 `backend` 后 nginx 502 | nginx 缓存了后端 IP | 已加 `resolver 127.0.0.11 valid=10s`；仍 502 就 `docker compose restart nginx` |
| 浏览器还在跑旧 chunk | 缓存了旧 `index.html` | nginx 已设 `index.html` 为 `no-store`；客户端首次 Ctrl+F5 |
| 容器里改的脚本重启后没了 | `/app` 是镜像内容、不是挂载 | 文件放宿主机 `deploy/plant/gateway/`，`docker compose build gateway` 后自动带上；临时用 `docker cp` |
