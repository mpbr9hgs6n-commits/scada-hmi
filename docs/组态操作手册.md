# 组态操作手册（WinCC 式编辑器）

> 品牌：陆祺智控（LUQI SMART CONTROL） · 适用：`http://192.168.1.100/scada` · 编写：2026-11-08
> 本手册只写**界面里真有的按钮和真能跑的行为**，菜单名与代码里的标签一致，照着点就行。

---

## 一、两个入口，别走错

| 地址 | 干什么 | 谁能进 |
|---|---|---|
| `/scada` | 画面列表（卡片/表格），新建、复制、删除、一键铺站 | 工程师 |
| `/scada/editor/<id>` | 组态编辑器（三栏：画面树 / 画布 / 属性） | 工程师 |
| `/view/<id>?site=S001` | **只读运行页**，给操作员/看板用 | 所有人（含 viewer） |

编辑器里**点对象是选中，不会写 PLC**；事件只在 `/view/` 页面里执行。这是硬规矩，不是 bug。

## 二、画一张画面，八步

1. **新建**：`/scada` 右上「新建画面」→ 填名字 → 选站点（站点画面必须选，否则树里看不到，只能靠 URL 直接开）。
2. **插入对象**：
   - 左侧「对象库」点一下对象（不是拖）→ 鼠标在画布上单击 → 落位。
   - 符号库图元、组件模板是**拖放**：按住拖到画布松手。
3. **摆位置**：拖动默认吃 **20px 网格**；按住 **Alt** 拖动 = 不吸附（像素级微调）。
4. **改外观**：右侧属性面板「几何 / 外观 / 字体 / 动态化 / 事件」五个页签，按对象类型自动裁剪（管道没有字体页，按钮没有动态化页）。
5. **绑变量**：「动态化」页签 → 选模式 → 目标属性 → 填表达式（见《变量命名规范》）。
6. **配事件**：「事件」页签 → 左树选事件 → 右表配动作（写点位 / 改属性 / 开画面）。
7. **保存**：`Ctrl+S`（走 `/api/page/<id>` 落库）。**不保存就等于没做**，刷新就没了。
8. **看效果**：`/view/<id>?site=S001`，或列表页的「预览」。

## 三、画布操作速查（都是真实现的快捷键）

| 操作 | 快捷键 / 手势 |
|---|---|
| 多选 | 框选 / `Shift` 点选 / `Ctrl+A` 全选 |
| 微移 | 方向键 1px，`Shift+方向键` 10px |
| 复制 / 粘贴 | `Ctrl+C` / `Ctrl+V`（原位 20px 偏移）；`Ctrl+Shift+V` 原位粘贴 |
| 再制 | `Ctrl+D` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`），**深度 100 步** |
| 删除 | `Delete` / `Backspace` |
| 组合 / 取消组合 | `Ctrl+G` / `Ctrl+Shift+G` |
| 上移一层 / 下移一层 | `Ctrl+]` / `Ctrl+[` |
| 对齐（多选时互相，单选时对画布） | `Ctrl+Shift+L/R/T/B` |
| 退出组内编辑 / 取消选择 | `Esc` |
| 缩放 | `Ctrl+滚轮`（10%~800%），工具栏可填百分比、可「适应窗口」 |
| 保存 | `Ctrl+S` |

> 面板上还有 `.drag-readout` 小浮标，拖动时实时显示 `x / y`，对齐靠它比目测准。

## 四、把变量接上：六种模式怎么选

属性面板「动态化」页签的「模式」下拉：

| 模式 | 什么时候用 | 关键点 |
|---|---|---|
| **直接变量连接** | 一个对象绑一个点位 | 表达式写 `S001.LEVEL` 或裸名 `LEVEL`（裸名=当前站点） |
| **间接变量连接** | 一张画面给 200 个站复用 | 写 `@CurrentSite + '.LEVEL'`；切站点时值自动换，**不刷新页面** |
| **动态对话框** | 按数值分档变色/闪烁 | 一条一条填「值域 → 属性值」，最后一档之上落到「其他」 |
| **动画** | 一个变量同时驱动多个属性 | 「属性」下拉选高度/不透明度/颜色…，每条都有自己的值域 |
| **文本列表 / 图形列表** | 数值换成文字 / 图片 | 先在 `/scada` 的「值列表」里建表，再在这里选 |

数据类型四选一（**这四档决定值域怎么算**）：

- `Analog`：按数值区间映射（最常用）
- `Bool`：非 0 = 1，只有两档
- `Bit`：取第 N 位（第 0 位是最低位）
- `Direct`：不做映射，值直接赋给属性（写 `1` 就是 `1`，不要拿来改颜色）

「其他」只有一个输入框，**填的是颜色**（面板上就是一行 `other`）。所以高度/不透明度这类数值属性在超出最后一档时会**夹到端点档位值**，不会掉成 0。

## 五、瞬时按钮（现场最容易配错的一个）

「事件」页签里选预设**瞬时（按下写 A，松开写 B）**，系统自动绑三条，且 `mouse.leave` **锁定不可删**：

| 事件 | 动作 |
|---|---|
| `mouse.press.left` | 写 1 |
| `mouse.release.left` | 写 0 |
| `mouse.leave` | 写 0 |

为什么要三条：按住拖出按钮再松手，`mouseup` 落在页面上、对象收不到，只有 `mouse.leave` 能把线圈复位。**少配一条，现场就是「泵停不下来」。**

其它保证：

- 松手兜底：按下过就记账，不管在哪松手都执行一次 release（甩出浏览器窗口也不漏）。
- 写被挡时补发：上一次写还没回来时，不丢这一次，记下终值等回来立刻补发。
- 防连点：同一个值 300ms 内重复点只发一次（避免设备抖）。

## 六、图层、组合、参考线

- **图层**：右侧「图层」面板，最多 **32 层**；可隐藏（`hidden`）、锁定（`locked`，锁定后点不中也拖不动）。层级顺序 = 数据里的 `items` 顺序，不按 id 重排。
- **组合**：多选 → `Ctrl+G`。组内子对象存的是**相对坐标**，移动组就是改组框一个数。**双击组**进组编辑，`Esc` 退出。
- **对齐参考线**：拖动对象时自动出现，跟其它对象的**起边 / 中心 / 止边**比，差 5px 内吸附；只对当前这一帧生效，松手不留在画面上。

## 七、组件模板（Faceplate）与一键铺站

1. 先建模板：`/scada` →「新建组件模板」→ 模板编辑器里画图 → 定义**接口变量**（如 `PV` / `RUN`）。
2. 画面里插入模板实例：对象库「组件模板」组，拖进来。
3. 每个实例只存 `fptId + bindings`（绑点位），**不拷贝模板 json** —— 所以改模板颜色，所有实例同时变。
4. 一键铺站：列表页选画面 →「铺站」→ 选站点 → 预览表会逐站列出「替换几处 / 几个无效点位」→ 执行。`@CurrentSite` 这类间接写法**原样保留**，不会被替换掉。

## 九、保存与发布

- `Ctrl+S` 保存；保存前可以看画布右下角「对象数」和性能读数。
- 只读页地址 `/view/<id>?site=<站点>`，可以直接投到看板/大屏 iframe。
- viewer 角色进不去编辑器，点「编辑」会被挡回列表并提示「无权限访问…」。
