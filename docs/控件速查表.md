## 四、标准对象（对象库 →「标准对象」）

线 / 折线 / 多边形 / 矩形 / 圆 / 椭圆 / 圆弧 / 静态文本。

共同可动态化属性：`fillColor` 填充色、`strokeColor` 边框色、`visible` 可见、`blink` 闪烁（周期可调）、`opacity` 不透明度、`text` 文字内容（仅文本对象）。

## 五、事件动作能改哪些属性

「事件」页签的动作目标可以是**点位**（写值）或**对象属性**（改界面）。可改的属性就是上面各表里标了「可动态化」的那些，常见组合：

| 想做的事 | 事件 | 动作 |
|---|---|---|
| 点按钮启动泵 | `mouse.click` | 写 `S001.PUMP1_CMD` = 1 |
| 按住才动作（点动） | 预设「瞬时」 | 按下 1 / 松开 0 / 移出 0（三条自动绑） |
| 点一下取反 | `mouse.click` | 预设「取反」 |
| 点击换画面 | `mouse.click` | 目标=画面，属性=`openPicture`，值=画面 id |
| 值超限让文本变红 | 动态化「动态对话框」 | 比事件稳，优先用动态化 |
| 画面打开时刷一次状态 | `picture.open` | 写一遍 `_CMD` 或改属性 |

**脚本动作（VBS / C）当前不支持**，选了会提示「二期支持」。见《已知限制》。
